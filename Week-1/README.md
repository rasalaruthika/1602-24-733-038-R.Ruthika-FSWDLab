Prelab Programs:
1.	Design a webpage that displays your name, branch, and college using heading and paragraph tags. 
2.	Demonstrate the use of common HTML text formatting tags such as bold, italic, underline, superscript, and subscript. 
3.	Create a webpage containing nested ordered and unordered lists to represent a course curriculum.
4.	Develop a webpage that uses an image as a clickable hyperlink to open another website.
5.	Design a webpage containing a table of contents with bookmark links that navigate to different sections of the same page.
6.	Construct a table to display student information with four columns and five rows also use rowspan and colspan attributes.
